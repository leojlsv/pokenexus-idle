# QA Artifacts

QA is normally returned through the canonical handoff protocol and does not need a file.

Persist a QA artifact here only when:
- the active task explicitly requires it;
- a high-risk audit needs durable evidence;
- the Human Owner requests it.

Naming:

```text
TASK-123-review.md
TASK-123-audit.md
```

Do not create generic `QA_REPORT.md`, dated report dumps, or duplicate completion summaries.
